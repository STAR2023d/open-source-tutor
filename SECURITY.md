# Security and child safety

Hesabu is used by children. We collect no accounts and no personal data; progress, nickname and buddy stay on the device.

Found a security problem or something unsafe for children? Please do not open a public issue.
Use GitHub's "Report a vulnerability" (Security tab) or contact the maintainers privately.

Never commit API keys. The content pipeline reads keys from environment variables only (`GEMINI_API_KEY`, `HESABU_API_KEY`).
